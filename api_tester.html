API Tester

Uma ferramenta simples para testar requisições HTTP, inspirada no Postman.

Exemplo: Authorization, Content-Type. Para uma API Flask local, normalmente Content-Type é suficiente.

O Body é enviado em requisições POST, PUT e PATCH. GET e DELETE não enviam corpo nesta ferramenta.
